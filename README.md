## How to visit a project

- **Visit an app:** use its **Open app** link in the table to launch the hosted project in a new tab.
- **Browse the collection locally:** open the repository's root `index.html` for the project gallery, with search, category filters, and grid or list views.
- **Run an app locally:** clone or download this repository, then open a project's `index.html` in a browser. For example, start with `todo-app/index.html` or `checklist-app/index.html`.
- **No setup needed:** the apps use browser storage for their data, so your tasks and checklists stay in that browser on that device.

## Adding a project

Create a new folder directly inside the repository root and add an `index.html`. Include a `<title>` and a description meta tag so the generated table can show a useful name and summary. When the change reaches `main`, GitHub Actions regenerates the table and commits it to this README.
